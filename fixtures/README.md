# Amostras de sintaxe

Abra os arquivos `showcase.*` para comparar as duas variantes. As amostras são
visuais: não formam um projeto executável e podem exigir extensões de linguagem
para fornecer Semantic Tokens. Em TSX, o React não está instalado de propósito.

Teste também com `editor.semanticHighlighting.enabled` definido como `false`.
Use **Developer: Inspect Editor Tokens and Scopes** para conferir os escopos.
